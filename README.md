## 🏁 About

**AutoVerge-platform** is a comprehensive solution streamlining the buying and selling of cars. It leverages modern technologies to deliver a slick user interface, secure transactions, and AI-driven recommendations.  
<sup><sub>Developed as a Final Year Project at Plymouth University.</sub></sup>

---

## ✨ Features

- 🔐 User authentication & profile management
- 🚘 Advanced car search & filtering
- 🤖 AI-powered smart recommendations
- 📋 List & manage vehicles for sale
- 💬 Secure messaging between buyers & sellers
- 🔔 Real-time notifications
- 💸 Payment integration for secure transactions
- ⭐ User & vehicle reviews/ratings
- 🛠️ Admin dashboard for listings & users
- 📱 Responsive, mobile-first design
